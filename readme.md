## Projetos em destaque

**[FinVise](https://github.com/No-Country-simulation/G9-BR-Team-17-FinVise)** · Plataforma de inteligência financeira (Hackathon ONE)
Projeto em equipe com React, TypeScript, Java 21, Spring Boot, Python e PostgreSQL, em arquitetura de múltiplos serviços. Importação de transações via CSV e Open Finance, classificação por IA, busca híbrida e agente conversacional (RAG) integrado aos dados financeiros.

**[challenge-g10-telentmatch-agent](https://github.com/kant-sdev/challenge-g10-telentmatch-agent)** · Agente de IA para triagem de currículos
Agente em Python e FastAPI com arquitetura RAG (SentenceTransformers + ChromaDB), integração com Google Gemini e APIs REST documentadas via Swagger/OpenAPI, para extração e recomendação de candidatos a partir de currículos em PDF.
